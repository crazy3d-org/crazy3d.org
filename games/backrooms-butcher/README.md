# Backrooms Butcher

Horror escape through endless yellow corridors while a relentless hunter pursues you. Equip weapons, search for keys and tools, solve environmental puzzles, and reach the exit.

## How to play

- **Goal:** Escape the maze before the butcher catches you.
- **Move:** WASD or arrow keys
- **Aim:** Mouse
- **Action:** Left click
- **Switch weapon:** Numpad keys (follow in-game prompts if different)
