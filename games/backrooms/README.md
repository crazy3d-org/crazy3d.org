# Backrooms

Horror survival in endless fluorescent corridors. Inspired by the Creepypasta lore, you navigate dim yellow rooms while managing noise and sanity against an unseen threat.

## How to play

- **Goal:** Survive as long as you can and find a way forward without drawing the lurking presence.
- **Move:** Arrow keys or WASD
- **Interact:** Spacebar
- **Look:** Mouse
