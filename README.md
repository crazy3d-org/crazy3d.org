# Crazy3D

Free browser games — play in seconds, no download.

**Homepage:** [https://crazy3d.org](https://crazy3d.org)

Crazy3D is a free HTML5 game site. Open a title in your browser and play — no install, no account required. The catalog mixes 3D and classic browser games with an unblocked, ready-to-play vibe. Pick something below and jump in.
